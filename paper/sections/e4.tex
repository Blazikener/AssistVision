All ablations use the dense MVS pipeline and change one factor at a time:
number of views (6, 8, 12, 16, 24, evenly spaced), image resolution and JPEG
quality (the OV2640 range), a deliberate error in the printed marker size
($\pm1$, $\pm2\%$), plate material, and three repeated runs of the identical
input to measure the run-to-run spread of SfM/MVS, which are not bit-deterministic.
A run fails if SfM returns no model, no marker side is triangulated, or
densification errors; failures are counted, not dropped, and the number of
registered views is reported for every run.
